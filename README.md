# 🩸 BloodDonor — Emergency Blood Donor Network

> A simple web experience designed to connect people who need blood with potential donors faster.

[![GitHub](https://img.shields.io/badge/Source-GitHub-181717?style=for-the-badge&logo=github)](https://github.com/pranav5376/BloodDonor) [![License](https://img.shields.io/badge/License-MIT-green?style=for-the-badge)](LICENSE)

## ❤️ The idea

During emergencies, finding a compatible blood donor quickly can be difficult. **BloodDonor** explores a simple, accessible interface for presenting donor information and making emergency blood-donation workflows easier to understand.

## ✨ Highlights

- 🩸 Emergency blood-donor focused experience
- 📱 Responsive, accessible interface
- ⚡ Lightweight frontend
- 🎯 Built around a real-world social-impact problem

## 🛠️ Tech Stack

**HTML5 • Tailwind CSS • JavaScript • Responsive Web Design**

## 🚀 Run locally

```bash
git clone https://github.com/pranav5376/BloodDonor.git
cd BloodDonor
```

Open `index.html` in a browser.
